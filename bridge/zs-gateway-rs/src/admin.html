Models

Models — fallback order

The list IS the order. #1 is the default — every chat uses it first. If it fails and fallback is on, the gateway tries #2, then #3, and so on. Use ↑ Up / ↓ Down to reorder.

off = only the default · on = try the next model in order

ACP facts for this build

Zerostack ACP exposes only initialize, session/new, session/prompt.
session/cancel does not exist → Stop ends the session's Zerostack process.
No session/load → the gateway stores transcripts and replays a text digest after a respawn.
MCP is disabled in ACP mode, so the vault tools are not available through this gateway.
