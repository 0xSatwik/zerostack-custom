# hoody-get-computer-not-proof
- trigger: the Hoody watch read "open" because a GET A COMPUTER button was present, but the Hub showed "No room right now — All servers are full" and creation failed (out of stock)
- rule: a "GET A COMPUTER" button is NOT proof of a slot — the watch must confirm a server is actually claimable before calling it open
- applies: hoody free-slot watch, any availability check
